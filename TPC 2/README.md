## Resumo 

O trabalho de casa desta semana consistia em desenvolver o jogo "Advinha o número" no programa em Python.

Este jogo tem duas modalidades: o computador pensa num número (entre 0 e 100) e o utilizador tenta adivinhar o mesmo ou o utilizador pensa num número (entre 0 e 100) e o computador tenta adivinhá-lo.

Além disso, uma vez descoberto o número, o programa termina imprimindo também o número de tentativas usadas para chegar ao resultado correto.
