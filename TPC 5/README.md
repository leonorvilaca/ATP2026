## Resumo 
Neste 5º trabalho de casa, criamos uma aplicação para a gestão de alunos de uma turma. Esta deve ter um menu de 7 operações, em que cada uma tem uma função diferente. A primeira deve criar uma turma, a segunda inserir um aluno na turma, a terceira listar a turma, a quarta consultar um aluno por id, a quinta guardar a turma em ficheiro, a sexta carregar uma turma dum ficheiro e por fim, sair da aplicação.
